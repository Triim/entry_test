# entry_test

Diagnostic Test — интерактивный тест из 20 заданий на вводные темы (математика, логика, работа с данными).

**Демо:** https://triim.github.io/entry_test/

## Стек

Чистая статика без зависимостей и сборки: `index.html` + `styles.css` + `script.js`.
Вся логика заданий и рендеринг — на ванильном JS, без внешних запросов.

## Локальный запуск

Открыть `index.html` в браузере — этого достаточно.
